# GitLessons

Git және GitHub-ты жаңадан үйренуге арналған қазақша оқу жобасы. [Сабақтар сайты](index.html) 25 видеодағы тақырыптарды бір жерге жинайды.

## Жобаны ашу

1. VS Code-та **File → Open Folder** таңдаңыз.
2. `C:\Users\user\OneDrive\Desktop\Codd\gitt` бумасын ашыңыз.
3. `index.html` файлын браузерде ашыңыз немесе VS Code-та **Open with Live Server** таңдаңыз.

## Репозиторий күйі

- Git репозиторийі: инициализацияланған.
- Негізгі тармақ: `main`.
- Қашықтағы репозиторий: `https://github.com/aigerim-max/GitLessons.git`.
- Алғашқы файл: `index.html`.
- Алғашқы push: терминалдан `main` тармағы GitHub-қа сәтті жіберілген.
- Жұмыс дәптеріндегі №3 және №6 сабақ қана осы жоба/терминал дәлелімен расталған. Қалған сабақтар орындалды деп белгіленбеді.

## Қолданылатын пәрмендер

```bash
git status
git add .
git commit -m "Update GitLessons"
git push
```

> №9 сабақ репозиторийді жою тақырыбына арналған. Нақты `GitLessons` репозиторийін жоймаңыз.
