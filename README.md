# GitLessons

Git және GitHub-ты жаңадан үйренуге арналған қазақша оқу жобасы. [Сабақтар сайты](index.html) мен [25 сабақтың жұмыс дәптері](LESSONS.md) плейлист тақырыптарын ретімен береді.

## Жобаны ашу

1. VS Code-та **File → Open Folder** таңдаңыз.
2. Жоба орналасқан `GitLessons` бумасын ашыңыз.
3. `index.html` файлын браузерде ашыңыз. Беттің сыртқы көрінісі `styles.css` файлы арқылы беріледі.

## Репозиторий күйі

- Git репозиторийі: инициализацияланған.
- Негізгі тармақ: `main`.
- Қашықтағы репозиторий: `https://github.com/aigerim-max/GitLessons.git`.
- Жоба файлдары: `index.html`, `styles.css`, `README.md`, `LESSONS.md`, `.gitignore`.
- Алғашқы push: терминалдан `main` тармағы GitHub-қа сәтті жіберілген.
- Осы компьютердегі орындалған жұмыспен расталған сабақтар: №2, №3, №6, №12, №14–18 және №24.
- GitHub веб-бетіндегі Gist, Pages, профиль және Fork/PR әрекеттері әлі жасалмаған.
- Жаңа commit-терді GitHub-пен синхрондау: `git push origin main`.

## Қолданылатын пәрмендер

```bash
git status
git add index.html styles.css README.md LESSONS.md .gitignore
git commit -m "Update GitLessons"
git push
```

> №9 сабақ репозиторийді жою тақырыбына арналған. Нақты `GitLessons` репозиторийін жоймаңыз.
